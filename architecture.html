Factory Inventory Management System

Architecture overview: system layout, tech stack, and data flow

Overview

A demo full-stack dashboard for factory inventory, orders, demand, backlog, and spending. A Vue 3 single-page app calls a FastAPI REST backend, which serves data held in memory and loaded from JSON files at startup. There is no database, so changes do not persist across restarts.

Frontend on port 3000, backend on port 8001, single machine, no authentication.

System Architecture

Tech Stack

Frontend

  • Vue 3 (Options-style setup() with Composition API)
  • Vue Router 4 (history mode)
  • Vite 8 dev server and build
  • Axios for HTTP
  • Custom SVG charts, CSS Grid layouts
  • Built-in i18n (English, Japanese)

Backend

  • Python 3.11+
  • FastAPI with Uvicorn
  • Pydantic 2 models
  • uv for dependency management
  • JSON files as the data source

Tooling

  • pytest, pytest-cov, httpx (tests/backend)
  • Claude Code agents, skills, hooks (.claude/)
  • GitHub MCP and Playwright MCP (.mcp.json)
  • Node ^20.19 or >=22.12

Data Flow

Request lifecycle

  1. User changes a filter in FilterBar. It updates the shared refs in useFilters (period, location, category, status).
  2. The active view watches those refs and calls getCurrentFilters(), which maps them to warehouse, category, status, and month.
  3. api.js sends a GET with query parameters, skipping any filter set to all.
  4. FastAPI runs apply_filters() and filter_by_month() over the in-memory lists.
  5. Results pass through the Pydantic response_model and return as JSON.
  6. The view stores raw data in refs; computed properties derive chart and table values, and Vue re-renders.

Startup and data

  1. python main.py starts Uvicorn on port 8001.
  2. Importing mock_data.py reads every JSON file in server/data/ once.
  3. Handlers read these lists directly. Filtering builds new lists and never mutates the originals.
  4. Restarting the server reloads the files and discards any runtime changes.
  5. generate_data.py can regenerate the sample JSON.

When a JSON structure changes, update the matching Pydantic model.

Observations

  • api.js defines task and purchase-order calls (/api/tasks, /api/purchase-orders), but main.py has no matching routes. Those calls would return 404 against the current backend, even though the Pydantic models for purchase orders exist.
  • views/Backlog.vue exists but is not registered in the router in main.js.
  • The API base URL is hard-coded to http://localhost:8001/api, and CORS allows every origin. Both are fine for a local demo and need changing before any deployment.
  • Inventory and dashboard inventory figures ignore the period filter, because inventory records have no date dimension.
